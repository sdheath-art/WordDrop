## 3. What changed today (all UNVERIFIED unless marked)

### Scoring: points come ONLY from detonating
Spencer: *"i dont think points should count for when you just make a word."*
- Removed both form-time payment sites in `HandManager.cs` (the `swapBaseScore` block and
  the swipe-claim block).
- `RulesEngine.DETONATION_SCORE_MULTIPLIER` **1.5 → 2.0** so a single word armed and fired
  immediately pays exactly what it used to: `before = Score + (1.5·S + 2)×2 = 4S + 4`,
  `after = (2.0·S + 2)×2 = 4S + 4`. Multi-word webs now pay MORE, because the slice that
  was flat now rides the triangular chain multiplier.

**⚠️ OPEN AND IMPORTANT:** there is **no pending/armed total on the HUD**. With no form-time
pay, the opening of a level scores literally nothing until the first detonation, which reads
as broken scoring. `RulesEngine.PreviewGroupPayout` (~line 304) already computes a connected
group's payout — it just has no display. **This is the most valuable next task.**

### Four bugs found in the live log and fixed
1. **BoardInvariants teleported the board during the stage-clear exit slide.** `CellToWorld`
   returns the RESTING layout; the exit slide offsets everything. The checker skips during
   board *entry* but `PrepBoardExit` deliberately leaves that flag false, so the exit had no
   guard — and the MISPLACED *repair* teleported every tile back onto a departing board.
   Fixed with `GridManager.BoardSlideOffsetX`, added to `want`.
2. **The rise animation was destroyed one frame after it began.** `AnimateRiseRow` drives
   `transform.DOMove` from outside `Tile`, so `IsAnimating` stayed false and the repair
   snapped tiles mid-rise. Added `Tile.MarkAnimating(seconds)` — a **deadline**, not an
   `OnComplete`, because rise tweens are routinely `DOKill`'d and a callback-cleared flag
   would strand true and blind the checker forever.
3. **Two systems seeded the board on every level transition** (ObjectiveManager AND
   LevelRules, one frame apart — visible in the log). This was Spencer's long-standing
   "there was already a board there and another animated over top of it". Fixed with
   `LevelRules.OwnsBoardSeed()`; ObjectiveManager stands down.
4. **The board sync snapped tiles mid-tween.** Threshold was `0.01` against a `0.959` cell
   with no `IsAnimating` check — 23 of 37 "pos drift" fixes printed an identical before and
   after. Now `CellSize * 0.25f` and skips animating tiles.

### Ice disappearing on a row rise — root-caused, three chained defects
1. `Tile._defrosting` was a plain bool set at the top of `DefrostCoroutine` and cleared at
   the bottom. Unity does **not** unwind a stopped/pooled/disabled coroutine, so any rise
   that recycled a mid-thaw tile stranded it true — after which `SetFrozenVisual(false)` hit
   its guard forever, including from `ResetForPool`. Now a **deadline**.
2. `SetFrozenVisual(true)` didn't restore the overlay's scale/position, so a tile recycled
   mid-melt came back active, flagged frozen, and scaled to nothing.
3. `ReconcileSpecialVisuals` compared `t.IsFrozen != c.IsFrozen` — **bookkeeping, not
   pixels**. Both true meant "fine". Added `Tile.FrostVisualHealthy` + `RepairFrostVisual()`,
   logged as `[IceRepair]`.

**Gameplay consequence, not cosmetic:** such a tile still refuses swaps (`HandManager` reads
`cell.IsFrozen`), so it was an *invisible blocker*.

### Level intro modal → points target + rules briefing
Icon and "GOAL" label removed. `LevelRules.BriefingFor(internalStage, target)` builds the
card body: target, then one line per rule that differs on this level, then on **levels 1–3
only** the core loop. Built in `LevelRules` because that file already owns the rules being
described. Cadence 2 is the default and deliberately NOT mentioned.
**This supersedes `feedback_wordrop_level_modal_goal_subtitle.md`** (already annotated).

### Home screen replaces the level map
`LevelMapPanel.HomeMode = true`. A **mode**, not a new class — the panel already owns the
background fit, hearts/coins pills, settings gear, overlay-pause handshake and the hand-off
into `LevelIntroModal`. Node/avatar/hop code is **skipped, not deleted**.

Flow: **home → press LEVEL N → LevelIntroModal → play.**

Background: `Assets/Resources/UI/levelmap@2x.png` (content is Spencer's `levelmp@2x.png`).

The big green button is **measured off a reference Spencer supplied**, solved numerically:
```
NAVY_RADIUS  0.208  of button height
BORDER_FRAC  0.104  of button height
RING_RADIUS  0.170  of face height
RING_INSET   0.145  of face height
PANEL_RADIUS 0.075  of face height   (strict nested value is 0.026; nudged up)
width 47.5% of canvas, aspect 2.42:1
```
Width comes from **anchors**, never a measurement. Height is derived from the resolved width
in a deferred pass. Y is clamped to the canvas. All three layers exist because measuring the
canvas at build time failed twice.

**⚠️ The label has NO TMP outline, deliberately.** An outline writes to `fontMaterial`, which
NRE'd earlier today and stopped the level map opening at all. The dark text rim is a second
label offset down. **If someone "improves" this with `SetOutlineThickness`, that is the bug
coming back.**

Coin payout restored: `RunHomeCoinCascade()` fires from behind/below the button into the
coins pill, reusing the existing `SpawnCoinCascade`.

### Cluster gold
A connected web now renders gold if **any** word in it is gold (`ClusterHasGold`), instead of
gold spreading only as far as a shared cell.
**⚠️ VISUAL ONLY.** `IsGold` (gold bonus cell) pays 2×; `HasHighValueLetter` has always been
visual-only. **Spencer has not yet said whether a gold cluster should also PAY 2× across the
whole web** — that would roughly double a 4-word web's payout and needs the level targets
